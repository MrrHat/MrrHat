###  About me

I don't really code — I just refuse to accept "no" from a computer. I team up with AI to turn ideas into actual working things, mostly Linux apps that deserve to exist on Windows too.

-  Currently obsessed with porting apps that shouldn't have been Linux-exclusive in the first place
-  Genuinely enjoy talking to people — hit me up if you want to chat, need help, or just want to yell about a bug
-  Learning by doing, one "why doesn't this work" at a time
-  Fun fact: my entire dev workflow is basically "describe the vibe, let AI cook, break it immediately, fix it together"
