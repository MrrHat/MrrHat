### About

I don't really code — I team up with AI to turn ideas into actual working things. Mostly Linux apps that deserve to exist on Windows too.

- Currently porting apps that shouldn't have been Linux-exclusive in the first place
- Genuinely enjoy talking to people — reach out if you want to chat, need help, or just want to yell about a bug
- Learning by doing, one "why doesn't this work" at a time
- My entire workflow is basically: describe the idea, let AI build it, break it immediately, fix it together
